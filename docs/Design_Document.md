## Design Document

### System Overview
The Birthday Cake Choice Maker uses a CLI interface to gather user preferences and suggest a dessert recipe.

### Functional Requirements
1. User selects: cake or cupcakes
2. User selects: yolk or no yolk
3. User selects: milk or no milk
4. User receives recipe info and chooses to view on-screen or via URL.

### Non-functional Requirements
- User-friendly, responsive, error-handling
