# Birthday Cake Choice Maker

A simple CLI tool to help users choose a birthday dessert based on preferences. User can choose different sets of choice combinations of milk or no milk, yolk or no yolk, and whole cake or cupcakes. If the program receives an invalid input, it will prompt the user to type in a valid input. The program can also take variations of valid inputs, and can inform the user of when their recipe choices do not have a matching recipe in the in-program database. The user can end the program anytime by typing "end program" to any of the input statements.
